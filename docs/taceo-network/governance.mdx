# Network governance

The TACEO Network is coordinated by TACEO in collaboration with independent node operators. This early model prioritises safety, reliability and controlled rollout for privacy-critical production workloads.

Current governance responsibilities include approving services and circuit deployments, managing node participation and infrastructure requirements, coordinating protocol and software upgrades, and managing incident response and operational continuity.

## Approval and deployment

Every change to what the network runs is reviewed and approved before it is deployed. Operators perform the deploy themselves, and every change is visible to the parties running the nodes.

Deployed code is publicly verifiable against what was approved.

## Verified execution

Nodes produce a proof that their execution was correct. Results are accepted only if that proof verifies, so correctness does not depend on trusting the operator that produced it.

## Application participation

Applications using the network are involved in upgrade coordination for the services they depend on. Major changes are coordinated through an offchain process with production integrators, so service evolution stays aligned with real workload requirements.

## Node participation

Node operators are currently curated to ensure reliability and security. Organisations with privacy-critical workloads may also participate as operators where appropriate. See [Node operators](/docs/taceo-network/node-operators).

## Evolution

Governance is expected to broaden as service adoption and operator participation grow. Future iterations may introduce additional shared-control mechanisms for service approvals, registry management and network standards.
