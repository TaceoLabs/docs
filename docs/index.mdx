# Welcome to TACEO

TACEO provides encrypted compute for applications that run on sensitive data without
exposing it. 

Our **Finance Solution** Merces, acts as a privacy layer for onchain finance. It enables private payments and tokenized assets on public blockchains - all powered by the TACEO Network.
The **Agent Solutions**, powers the x402 standard, to bring the same privacy to
agent-to-agent payments. 

Our **Identity Solutions** bring privacy-preserving verification to
identity systems. The TACEO network forms the privacy backbone for global-scale identity systems such as **World**, 
**zkPassport**, and **Boop**.

For what's live today — chains, frontends etc. — see [Deployments & status](/docs/start-here/deployments-and-status).

Confidential payments for AI agents, built on x402. Hides the asset and amount of an agent-to-agent transfer; sender and recipient stay onchain.
