# Quickstart

The cross-chain demo is live and public at [crosschain.merces-demo.taceo.io](https://crosschain.merces-demo.taceo.io/). It runs across three testnets, with a Merces deployment and a three-party MPC network on each.

| Network | Chain ID |
|---|---|
| Monad Testnet | 10143 |
| Sepolia | 11155111 |
| Base Sepolia | 84532 |

All three use LayerZero Endpoint V2 at `0x6EDCE65403992e310A62460808c4b910D972f10f`.

:::info Testnet only
Test tokens with no real-world value. Do not use mainnet private keys or real funds.
:::

## Before you start

A browser wallet with testnet funds on whichever chain you want to start from.

## Walk the flow

1. **Connect your wallet** and **register an account**. Registration signs you up with the ID registry on the acting chain — the same step as any Merces account.
2. **Pick your acting chain.** The demo can switch between the three networks; the one you select is where your next operation runs.
3. **Deposit** to move public funds into a private balance on that chain. The sequence is ZK proof, approve, deposit transaction, then MPC batch — around 15 seconds end to end.
4. **Bridge** to move that private balance to another chain. This is the cross-chain path described in [How it works](/docs/finance-solutions/cross-chain/how-it-works): debit on the source chain, LayerZero message, credit on the destination.
5. **Withdraw** on the destination chain when you want public ERC-20 back. This is the point at which tokens are actually minted to you.

Transfer is also available for private-to-private movement within a single chain.

Read [What the demo does not do](/docs/finance-solutions/cross-chain/limitations) before drawing conclusions about the privacy or trust properties of what you're testing.

## Exiting without the operators

The demo also exposes **Redeem** and **Challenge**. These are the escape hatch: the path for recovering funds without the MPC network's cooperation. See [Escape hatch](/docs/finance-solutions/concepts/escape-hatch).
