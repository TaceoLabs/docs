# Payments, payroll & batch

On public rails, a single payroll or supplier run exposes every recipient, every amount, and the timing. That is a salary band, a vendor list and a cash-flow signal, readable by competitors and by anyone watching the chain.

## What Merces adds

**Batch disbursement from one private account.** Pay many recipients in a single run, with balances and amounts encrypted and the result verified onchain by proof.

**The right privacy per flow.** Domestic payroll can run in confidential mode, where amounts are hidden and parties visible. Cross-border settlement can run private, hiding parties as well. The mode is selected per transaction, not fixed for the deployment.

**Compliance in the flow.** Screening runs on funds entering and leaving the private account, and past activity can be disclosed to authorised parties on request. See [Compliance](/docs/finance-solutions/compliance/overview).

**No migration.** Runs on the EVM chain the business already uses, integrated by API and SDK, white-labelled so end users never see TACEO.
